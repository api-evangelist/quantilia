# Quantilia

> Quantilia is a Nice, France based financial data and portfolio reporting platform for
> institutional investors, family offices, asset managers, private banks, insurance
> companies, and corporates and endowments. It aggregates fragmented investment data

## Agent notice — there is no public API

Quantilia markets API delivery ("Output as files, dashboards, or API feeds for
downstream systems") but publishes NO public developer portal, NO API reference,
and NO machine-readable specification. There is nothing an agent can call.

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Postman collection or JSON Schema is
  published at any Quantilia host.
- The API host https://api.quantilia.com/ resolves and runs nginx, but returns
  HTTP 403 Forbidden to every unauthenticated request, including the root path.
  This is consistent with an IP-allowlisted or tenant-scoped client API.
- The customer application at https://app.quantilia.com/ is a login-gated
  single-page app. It answers HTTP 200 with the same 251-byte meta-refresh HTML
  shell for every path, so any "200" you get from it is a catch-all, not a document.
- No /.well-known/ document is served on any host.
- No MCP server, no A2A agent card, no webhooks, no event stream.

Access to the API surface requires a commercial agreement. Start at
https://www.quantilia.com/book-a-demo/ or email sales@quantilia.com.
